# 飞行雪绒历险记

躲避弹幕生存游戏，纯 HTML/CSS/JS 实现，双击 `飞行雪绒历险记.html` 即可运行。

## 目录结构

```
飞行雪绒历险记（网页）/
├── 飞行雪绒历险记.html   # 游戏主文件
├── character/             # 角色图片（在 CHARACTER_IMAGE_PATHS 数组中配置）
├── skill_character/       # 大招效果图（在 SKILL_IMAGE_PATHS 数组中配置）
└── README.md
```

## 操作说明

| 按键 | 功能 |
|------|------|
| `W A S D` / 方向键 | 惯性移动（松手保持运动，按键匀加速） |
| `空格` | 大招：清除全部弹幕 + 积分 +10，冷却 5 秒 |
| `Q` | 消耗 10 积分，随机回复 20~50 HP，冷却 5 秒 |
| `E` | 长按：弹幕减速 70% + 计时减速，每秒 -1 积分 |
| `F` | 最终得分 ≥ 500 时召唤传送门，靠近后按 F 结算 |
| `ESC` | 暂停 / 继续 |
| `R` | 重置回选人界面 |

## 游戏规则

### 生命与计时
- **100 点生命值**，受伤扣除弹幕上标注的伤害值（0~10），归零失败
- **180 秒倒计时**，归零存活成功
- 受伤后 1 秒无敌闪烁
- 每受伤 1 HP，场上弹幕上限 +1

### 弹幕
- 红/黄/蓝/紫/粉 五种颜色，空心环形外观，红色数字标注伤害值
- 碰到画布边缘反弹并加速 5%
- 基础上限 25 颗
- 大招持续期间暂停生成新弹幕
- 游戏结束后弹幕冻结

### 积分球
- 绿色实心圆球，分值 1~10（越大分越高），触碰收集
- 场上总分保持 50~100，总球数 8~20
- 吃掉一个后随机生成 0~2 个新球

### 结算
- **最终得分 = 积分 × 剩余 HP 百分比**
- ≥ 500 分可召唤传送门提前结算
- ≥ 1005 分触发神秘彩蛋

## 自定义配置

### 修改角色图片

编辑 HTML 文件中的 `CHARACTER_IMAGE_PATHS` 数组：

```js
const CHARACTER_IMAGE_PATHS = [
  './character/角色1.png',
  './character/角色2.png',
  // 添加更多图片路径...
];
```

也可在选人界面点击「追加角色图」手动加载。

### 修改大招效果图

编辑 `SKILL_IMAGE_PATHS` 数组：

```js
const SKILL_IMAGE_PATHS = [
  './skill_character/大招效果图1.png',
  './skill_character/大招效果图2.png',
  // 添加更多...
];
```

### 调整游戏参数

所有可调参数集中在 `<script>` 开头附近：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `GAME_DURATION` | 游戏时长（秒） | 180 |
| `SKILL_COOLDOWN` | 大招冷却（秒） | 5 |
| `Q_COOLDOWN` | Q 技能冷却（秒） | 5 |
| `Q_HEAL_MIN/MAX` | Q 技能回复范围 | 20~50 |
| `E_BULLET_SLOW` | E 技能弹幕减速比例 | 0.3 |
| `BASE_MAX_BULLETS` | 基础弹幕上限 | 25 |
| `ORB_SUM_MIN/MAX` | 积分球总分范围 | 50~100 |
| `ORB_COUNT_MIN/MAX` | 积分球数量范围 | 8~20 |
| `SKILL_IMG_SCALE` | 大招图片缩放比例 | 0.45 |

### 打包为 EXE

可使用 [NW.js](https://nwjs.io/) 或 [Electron](https://www.electronjs.org/) 将 HTML 文件夹打包为独立可执行文件。所有资源使用相对路径，无需额外配置。
